# VATranscribeWeb

Commercial SaaS/Web repository for VATranscribe.

## Purpose

- marketing landing and SEO site
- user web app
- admin panel
- FastAPI backend
- Celery worker
- desktop app shell
- billing, subscriptions, payments, fiscal receipts
- usage quotas and credits
- licenses and devices
- affiliate, ads and sponsored placements
- security, privacy and compliance foundation

## Main apps

apps/marketing - public landing, SEO, docs, blog, legal pages
apps/web - user dashboard and SaaS application
apps/admin - internal admin panel
apps/api - FastAPI backend
apps/worker - Celery background workers
apps/desktop - desktop application shell
