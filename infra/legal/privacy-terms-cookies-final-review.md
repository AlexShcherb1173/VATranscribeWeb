# P3-06 Privacy / Terms / Cookies final review checklist

VATranscribeWeb production legal activation artifact.

## Documents to review

- Privacy Policy.
- User Agreement / Terms.
- Cookie Policy.
- Consent to personal data processing.
- Consent to analytics/cookies.
- Data deletion/export instructions.
- Refund/payment policy if paid billing is enabled.

## Privacy Policy checks

- [ ] Operator details are real and consistent across product, API, and marketing pages.
- [ ] Contact emails are monitored.
- [ ] Personal data categories are listed.
- [ ] Purposes of processing are listed.
- [ ] Legal basis/consent flow is described.
- [ ] Retention periods are described.
- [ ] Deletion/export request process is described.
- [ ] Processors/subprocessors are listed or categorized.
- [ ] Cross-border transfer is described if applicable.
- [ ] 152-ФЗ / Russian personal data localization position is reflected if applicable.
- [ ] Security measures are described without overclaiming.

## User Agreement / Terms checks

- [ ] Service scope is accurate: download, transcription, export, user account, billing if enabled.
- [ ] User responsibility for uploaded content is described.
- [ ] Prohibited use is described.
- [ ] Availability/disclaimer clauses are reviewed.
- [ ] Billing/refund clauses are disabled or accurate.
- [ ] Account termination/deletion clauses are reviewed.
- [ ] Governing law and dispute clauses match operator status.

## Cookie Policy checks

- [ ] Necessary cookies are listed.
- [ ] Analytics cookies/scripts are consent-gated.
- [ ] Marketing pixels are disabled or consent-gated.
- [ ] Yandex Metrika / GA4 / other providers are included only when actually enabled.
- [ ] Cookie consent versioning is documented.
- [ ] Withdrawal/change consent path is described.

## Technical consistency checks

- [ ] Backend legal document versions match frontend/marketing documents.
- [ ] Registration requires required legal documents.
- [ ] Cookie banner blocks non-essential analytics before consent.
- [ ] Privacy export/delete endpoints are documented.
- [ ] Production config guardrails reject neutral legal placeholders.

## Secret and personal data handling notice

DO NOT commit reviewed documents containing private operator data that is not intended for publication, private legal comments, contracts, personal identifiers, provider tokens, payment keys, or runtime secrets.

This checklist is not legal advice. It is a release control for final human review.
